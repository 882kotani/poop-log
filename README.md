# うんちログ (Poop Log)

1歳の娘の排便状況を、保護者がスマートフォンから簡単に記録・確認できる育児支援WEBアプリケーションです。

---

## 1. アプリの概要と目的

育児中に手間をかけず、片手操作で排便の日時・回数・備考を即座に記録し、日ごとの健康状態を振り返れるようにすることを目的としています。
最優先事項は、**記録のしやすさ**、**データの確実な保存**、**スマートフォンでの操作性**、そして**シンプルで清潔感・温かみのあるデザイン**です。

---

## 2. 主な機能

- **ワンタップ排便記録**: 画面中央の大きなボタンを1回押すだけで、日本時間（JST）の現在時刻で即座に記録を保存。
- **今日の排便状況サマリー**: 今日の排便回数を「今日のうんち 3回」のように大きく視認性高く表示。
- **日付ナビゲーション**: 「前日」「翌日」ボタンやカレンダー選択から過去・未来の日付を柔軟に確認。
- **うんちの履歴（タイムテーブル表）**: 縦軸に「0時〜23時」、横軸に「うんち」を配置した表形式を採用。一目でどの時間帯に出たか（または出ていないか）を直感的に確認可能。各時間帯セル内で時刻の確認、備考の閲覧、編集・削除が可能。
- **備考・日時の編集**: 排便時間や「少しかため」「いつもより多め」などの備考（最大500文字）をモーダルから編集可能。
- **二重登録防止ガード**: 画面側のボタン無効化およびサーバー側のタイムスタンプ検証により、二重送信を自動抑止。
- **削除確認ガード**: 誤タップによる誤削除を防ぐための確認モーダルを完備。
- **アプリ情報（README）閲覧モーダル**: ヘッダーの ℹ️ アイコンから、いつでも仕様や操作方法を確認可能。

---

## 3. 使用技術と対応バージョン

- **フロントエンド**: HTML5, CSS3, JavaScript (Vanilla JS) ※フレームワーク・CDN完全不使用
- **バックエンド**: Node.js (v18.0.0 以上), Express (v4.19.2)
- **データベース**: SQLite3 (`better-sqlite3` v9.4.3)
- **通信形式**: JSON REST API

---

## 4. 必要な環境

- **Node.js**: v18.0.0 以上
- **npm**: v8.0.0 以上
- **better-sqlite3 の動作要件**:
  - `better-sqlite3` はC++ネイティブアドオンを含みます。多くの主要プラットフォーム（macOS, Linux, Windows x64/arm64）向けにはプリビルド済みバイナリが自動提供されます。
  - ソースコードからビルドされる環境の場合は、Python 3 および C++ コンパイラ（GCC/Clang, Visual Studio Build Tools 等）が事前にインストールされている必要があります。
